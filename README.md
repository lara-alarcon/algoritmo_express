# Algoritmo Express (.EXE)

## Descripción
**Algoritmo Express** es un videojuego de lógica y resolución de problemas tipo puzzle diseñado para poner a prueba la agilidad mental y el razonamiento algorítmico de los jugadores. 
El objetivo principal es completar secuencias de pasos lógicos dentro de escenarios limitados, simulando un entorno de procesamiento de datos rápido y eficiente.

El juego presenta una estética Retro Terminal con una paleta de colores neón, buscando una experiencia inmersiva que recuerda a los primeros entornos de programación.

## Características Principales
* **Mecánica de Juego:** Resolución de puzzles mediante el ordenamiento y selección de secuencias.
* **Sistema de Ranking:** Compite por el mejor puntaje basado en tu tiempo de respuesta y la precisión.
* **Estética Retro:** Gráficos estilo pixel-art con una interfaz minimalista.

---

## Stack Tecnológico
* **Lenguaje:** Python 3.11.0
* **Librería Gráfica:** Pygame 2.6.1
* **Fuentes:** Press Start 2P (Pixel Art).

---

## ¿Cómo jugar?
1. Ejecuta el archivo `main.py`.
2. Ingresa tu nombre y edad en el menú de registro.
3. Completa los desafíos lógicos en el menor tiempo posible.
4. Consulta el Top 6 de mejores jugadores en la pantalla inicial.

---

## Instalación y Ejecución
1. Asegúrate de tener instalado Python 3.11.0 o superior.
2. Instala la dependencia de Pygame ejecutando el siguiente comando:
  <br>pip install pygame
3. Para iniciar el juego, abre tu terminal en la carpeta del proyecto y ejecuta:
  <br>python main.py
